# Fonts (self-hosted)

Served from this site so no student device contacts Google to load fonts.

| Font | Files | License |
|---|---|---|
| Atkinson Hyperlegible (Braille Institute) | 400, 700 (Latin subset) | SIL Open Font License 1.1 (LICENSE-atkinson-hyperlegible.txt) |
| Baloo 2 (Ek Type) | 600, 700, 800 (Latin subset) | SIL Open Font License 1.1 (LICENSE-baloo-2.txt) |

Source: the `@fontsource` npm packages (WOFF2 files, unmodified). Latin subset only; the app is English-language.
If a browser cannot load them, CSS falls back to system fonts (Trebuchet MS / Verdana / system-ui).
